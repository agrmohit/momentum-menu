Better handling of Bluetooth turning off and on. Changes since [v2.2.1](https://github.com/agrmohit/momentum-menu/releases/tag/v2.2.1).

## Connection

- **Bluetooth off:** the app now says Bluetooth is off. Before, it wrongly said the headphones were not paired.
- **Headphones switched on:** the app connects within a second. Before, it could take up to a minute.
- **Bluetooth turned back on:** if the headphones were connected to this Mac before, and Bluetooth was off for less than 30 minutes, the app reconnects them. Before, you had to click **Try Again**.
- **After Disconnect:** the app stays disconnected until you click **Reconnect**, as before.

## Install

Needs macOS 26 on Apple silicon.

1. Optional: check the download was built by this repo's release workflow, from this tag. Either verify its attestation, or compare its checksum with the `.sha256` file beside it:

   ```sh
   gh attestation verify MomentumMenu-2.3.0.dmg -R agrmohit/momentum-menu
   shasum -a 256 -c MomentumMenu-2.3.0.dmg.sha256
   ```

2. Open the DMG and drag Momentum Menu to Applications.
3. The app is ad hoc signed, not notarised, so macOS blocks the first launch. The attestation does not change that: macOS checks only Apple signing. Open the app once, then choose **Open Anyway** in System Settings > Privacy & Security within the hour. Or clear the quarantine flag from a terminal:

   ```sh
   xattr -dr com.apple.quarantine /Applications/MomentumMenu.app
   ```

4. Open it and allow Bluetooth when asked.
