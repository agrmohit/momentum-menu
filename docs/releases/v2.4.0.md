Forget a paired device from your Mac. Changes since [v2.3.0](https://github.com/agrmohit/momentum-menu/releases/tag/v2.3.0).

## Paired devices

- **Forgetting a device:** right-click a paired device that is not connected, choose **Forget**, and confirm in the row. The headphones erase its pairing. Before, only Smart Control could do this.
- **Right-click a device:** the menu also offers its **Connect** or **Disconnect**, the same as its pill.
- **After a device is forgotten anywhere:** the paired devices still load, from this app or Smart Control. Before, the gap a forget leaves hid the list, and with it Connect and Disconnect, until the headphones restarted.
- **Disconnecting or forgetting another device:** offered only on firmware 3.38.3, the version both were tested on. Before, Disconnect was also offered on newer firmware, where nobody had tried it.
- **The icon you picked for a forgotten device:** it is dropped too, so a new device with the same name starts from the guess.

## Troubleshooting

- **Seeing what the app sends the headphones:** every message now goes to the macOS log at debug level. The README's developer notes give the `log stream` command to watch it.

## Install

Needs macOS 26 on Apple silicon.

1. Optional: check the download was built by this repo's release workflow, from this tag. Verify its attestation and that it belongs to this release, or compare its checksum with the `.sha256` file beside it:

   ```sh
   gh attestation verify MomentumMenu-2.4.0.dmg -R agrmohit/momentum-menu
   gh release verify-asset v2.4.0 MomentumMenu-2.4.0.dmg -R agrmohit/momentum-menu
   shasum -a 256 -c MomentumMenu-2.4.0.dmg.sha256
   ```

2. Open the DMG and drag Momentum Menu to Applications.
3. The app is ad hoc signed, not notarised, so macOS blocks the first launch. The attestation does not change that: macOS checks only Apple signing. Open the app once, then choose **Open Anyway** in System Settings > Privacy & Security within the hour. Or clear the quarantine flag from a terminal:

   ```sh
   xattr -dr com.apple.quarantine /Applications/MomentumMenu.app
   ```

4. Open it and allow Bluetooth when asked.
