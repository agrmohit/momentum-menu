No change to the app since [v2.1.1](https://github.com/agrmohit/momentum-menu/releases/tag/v2.1.1). This release changes how releases are made.

## Build and release

- A release is published only after CI passes on the tagged commit: a clean build of the app and tests with warnings as errors, then the full test suite.
- CI also runs on every push to `main` and on pull requests.
- A Makefile wraps the common tasks. `make check` is what CI runs, `make install` builds and installs, and `make` lists every target.
- A compiler warning in one test is fixed.

## Install

Needs macOS 26 on Apple silicon.

1. Optional: check the download was built by this repo's release workflow, from this tag. Either verify its attestation, or compare its checksum with the `.sha256` file beside it:

   ```sh
   gh attestation verify MomentumMenu-2.1.2.dmg -R agrmohit/momentum-menu
   shasum -a 256 -c MomentumMenu-2.1.2.dmg.sha256
   ```

2. Open the DMG and drag Momentum Menu to Applications.
3. The app is ad hoc signed, not notarised, so macOS blocks the first launch. The attestation does not change that: macOS checks only Apple signing. Open the app once, then choose **Open Anyway** in System Settings > Privacy & Security within the hour. Or clear the quarantine flag from a terminal:

   ```sh
   xattr -dr com.apple.quarantine /Applications/MomentumMenu.app
   ```

4. Open it and allow Bluetooth when asked.
