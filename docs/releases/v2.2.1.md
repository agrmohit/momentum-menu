A smaller app, and crash reports that can be read. Changes since [v2.2.0](https://github.com/agrmohit/momentum-menu/releases/tag/v2.2.0).

## Build

- The app binary is stripped, as Xcode does for an app. It drops from 1.6 MB to 0.7 MB once installed. The DMG is about the same size, because it was already compressed.
- The binary no longer carries a debug map naming the build machine's files.
- Each release now has a `MomentumMenu-2.2.1.dSYM.zip` beside the DMG. It turns the addresses in a crash report back into function names and lines. If the app crashes, attach the report from Console to an issue; you do not need the dSYM yourself.
- The attestation covers the dSYM zip as well as the DMG.

## Install

Needs macOS 26 on Apple silicon.

1. Optional: check the download was built by this repo's release workflow, from this tag. Either verify its attestation, or compare its checksum with the `.sha256` file beside it:

   ```sh
   gh attestation verify MomentumMenu-2.2.1.dmg -R agrmohit/momentum-menu
   shasum -a 256 -c MomentumMenu-2.2.1.dmg.sha256
   ```

2. Open the DMG and drag Momentum Menu to Applications.
3. The app is ad hoc signed, not notarised, so macOS blocks the first launch. The attestation does not change that: macOS checks only Apple signing. Open the app once, then choose **Open Anyway** in System Settings > Privacy & Security within the hour. Or clear the quarantine flag from a terminal:

   ```sh
   xattr -dr com.apple.quarantine /Applications/MomentumMenu.app
   ```

4. Open it and allow Bluetooth when asked.
